# Collab Board

Offline-first collaborative kanban and whiteboard on Angular 22 and Yjs (CRDT): real-time sync between tabs, presence, per-user undo, history time-travel and a visual demo of concurrent edits converging.

> Work in progress. The live demo will be at https://usertrv.dev/projects/collab-board/. What remains is listed in [NEXT_STEPS.md](NEXT_STEPS.md).

```bash
pnpm install
pnpm start
pnpm test
pnpm build
```
