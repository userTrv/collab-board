Cross-device sync Experimental

Tabs of this browser always sync (BroadcastChannel). To sync between devices, boards can use peer-to-peer WebRTC via y-webrtc. It needs a signaling server you trust — public ones are often down, so this is off by default and the rest of the app never depends on it. Both devices must open the same board link.
